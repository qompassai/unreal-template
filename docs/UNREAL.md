# Unreal Engine quickstart

Unreal: https://www.unrealengine.com/ — docs at
https://dev.epicgames.com/documentation/en-us/unreal-engine/

- New projects start in the editor (File > New Project); keep
  this repo for docs, automation scripts, and shared config.
- Version control: enable Git LFS for `.uasset`/`.umap`; never
  commit `Binaries/`, `DerivedDataCache/`, `Saved/`.
- CI: UnrealBuildTool / BuildGraph for headless builds.
